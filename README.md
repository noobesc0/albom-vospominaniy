# Альбом воспоминаний — v6

Открыть `index.html`.

## Что работает
- Кнопка «Меню» теперь находится в шапке справа.
- Открывается компактное меню с вкладками «Альбом», «Любимые фото», «Редактирование».
- «Альбом» и «Любимые фото» прокручивают страницу к нужному разделу.
- «Редактирование» позволяет выбирать фото с компьютера, задавать название, описание и категорию.
- Добавленные фотографии сохраняются в IndexedDB браузера, поэтому большие изображения не упираются в маленький лимит localStorage.
- Можно создавать категории, менять данные фото, удалять фото и отмечать главное фото для верхнего блока.
- Работают сортировка, любимые фото, просмотр отдельного фото, полноэкранный режим, просмотры и комментарии.

Это локальная демо-версия: данные хранятся только в браузере на этом компьютере. Для настоящего публичного сайта с доступом с разных устройств нужен сервер/облачное хранилище.
